Question 1: Choosing an SVM kernel

I used the 462 observations and the same nine predictors as in Homework 7, with famhist coded Absent=1 and Present=2. I assigned five stratified folds using seed 432 (sizes 93, 93, 92, 92, 92). Every candidate used these same folds. In each fold, I subtracted the fitting-set means and divided by the fitting-set standard deviations, then applied that transformation to the validation rows.

I fixed 20 candidates before fitting. For polynomials, K(x,z) = ((x dot z)/9 + 1)^degree; thus gamma=1/9 and coef0=1. For the radial kernel, K(x,z) = exp(-gamma ||x-z||^2). I used unweighted SVC classes and solver tolerance 0.000001. Gamma does not apply to the linear kernel. Each reported CV error is the unweighted mean of the five validation misclassification rates.

I prefer the cubic polynomial with C=0.1, gamma=1/9, and coef0=1 for this comparison: its mean CV error is 0.2577, versus 0.2706 for the best linear setting and 0.2684 for the best radial setting. It made 119 held-out mistakes across the folds. The pooled rate, 119/462=0.2576, differs slightly from the reported mean because fold sizes differ. The advantage over linear is only about 1.3 percentage points, so I would not call it strong evidence that a nonlinear boundary is needed. Larger C generally hurt the polynomial models here, consistent with fitting the training data too closely. This CV minimum is a tuning result, not an independent test-error estimate.

The response is chd; predictors are sbp, tobacco, ldl, adiposity, famhist, typea, obesity, alcohol, and age, with famhist coded Absent=1, Present=2. The minimum CV error was 0.2598 (linear, C=10). The one-SE cutoff was 0.2794. I chose linear C=0.1 (CV 0.2629): it was within that cutoff and had the smallest C in the preferred family. The fixed preference was linear, polynomial degrees 2-4, then radial. Across seeds 432-436, this setting was selected 4/5 times; all five selections were linear. Nonlinearity did not give a clear gain here.

Refitting used 201 support vectors (100 class 0, 101 class 1). Test error was 39/139 = 0.2806; always predicting class 0 would give 48/139 = 0.3453. The confusion matrix (observed rows, predicted columns, order 0,1) was [[75,16],[23,25]]. The positive-class miss rate was 23/48 = 0.4792. Missing nearly half the CHD cases is a substantial limitation. These results describe one small split, not a guaranteed future error rate.

# SVM analysis

Use only when explicitly invoked; keep this folder outside automatic skill directories.
Receive the data, response, predictors, coding, and any validation restrictions separately.

1. Check class counts, types, missingness, constants, duplicates, and leakage. Explain SVM suitability; resolve data problems before fitting.
2. Reserve a stratified 30% test set, seed 432, before comparison. Respect group/time structure if needed. Exclude test rows from tuning and skill revisions.
3. Include a linear baseline; explain whether polynomial and radial kernels offer useful nonlinear alternatives.
4. Fix the grid before fitting. Defaults: linear C={0.1,1,10}; polynomial degrees={2,3,4}, C={0.1,1,10}, gamma=1/p, coef0=1; radial C={0.1,1,10,100}, gamma={0.01,0.1}. Here p is the predictor count. These are 20 candidates; state changes and fixed settings.
5. Save five stratified training folds, seed 432; reuse them across candidates. Fit scaling and other learned preprocessing only on each fold's fitting rows. Report failed fits.
6. Calculate each candidate's mean validation misclassification rate and SE=sample SD/sqrt(5). Select using unrounded values. This SE is a heuristic, not a confidence interval.
7. Keep candidates within the minimum mean error plus the minimum-error candidate's SE. Prefer linear, then polynomial degrees 2,3,4, then radial; within families prefer smaller C, then smaller gamma. This is a simplicity convention, not a universal ranking.
8. Repeat training CV with seeds 433-436 and the same grid/rule. Report selection stability; do not expand the search in response.
9. Freeze the choice, refit on all training rows, and evaluate once on test rows. Report mistakes/n, error, confusion matrix (observed rows), and positive-class miss rate. Identify the positive class; do not revise after testing.
10. Save code, versions, split/fold assignments, candidate results, and fitted model. Recompute errors from saved predictions and independently check decision scores.

Write at most one printed page at 11-point font: plain selectable text, one CV comparison figure, and one settings/error table (best per family plus the selected setting if different).
State data/coding, seed, split sizes, preprocessing, kernels, selection rule, selected settings, support-vector counts, and test results. Briefly explain the comparison and uncertainty; avoid causal or global-optimum claims.
Keep the invocation, full grid, code, and skill outside this page. Render and inspect the layout without shrinking text.

Calculation checks

All 20 main CV means in both questions matched a separate GridSearchCV calculation using the saved folds and fold-fitted scaling. Saved out-of-fold predictions reproduce each fold's error and mistake counts. The final decision scores were independently reconstructed from the support vectors and dual coefficients; the predictions and test confusion matrix agree. No candidate failed to converge. Full settings, predictions, split/fold assignments, and software versions are saved in the working files. Python 3.12.14 and scikit-learn 1.9.1 were used. The selection workflow was fixed before test evaluation. Later wording edits shortened the skill without changing its analysis rules.
