The correlation is 0.9977. The largest and smallest singular values are 14.141 and 0.475. The first two columns are therefore almost redundant.

The sum of their coefficients controls the shared direction in the two columns. There is a lot of information in that direction. The difference moves the two coefficients in opposite directions, and this barely changes the fitted values because the columns are so similar. That nearly flat direction is connected to the small singular value, so response noise can produce a large change in the estimated difference.

c. Interpretation

OLS is nearly unbiased on average, but its first two coefficient estimates move a lot from one response sample to another. Their difference is especially unstable even though the sum stays close to 3.

At lambda 0.02, the individual standard deviations and the standard deviation of the difference fall sharply. The sum changes much less because ridge mostly removes movement in the weak direction. At lambda 0.2, the estimates are steadier again, but the sum is pulled farther below 3. This is visible as shrinkage bias, and the average test MSE starts increasing.

The fitted values do not change as much as the individual coefficients because a large positive change in the first coefficient can be offset by a large negative change in the second one. Ridge stops much of that exchange between the two coefficients without needing to move the fitted response by the same amount.

Question 3: What does ridge regression shrink?

a. Normal equation

Differentiating the objective gives

∇Lλ(𝛃)=−1n𝐗𝖳(𝐲̃−𝐗𝛃)+λ𝛃. \nabla L_\lambda(\boldsymbol\beta) = -\frac{1}{n}\mathbf X^{\mathsf T} (\widetilde{\mathbf y}-\mathbf X\boldsymbol\beta) + \lambda\boldsymbol\beta.

At the minimum the gradient is zero, so

1n𝐗𝖳𝐗𝛃̂λ+λ𝛃̂λ=1n𝐗𝖳𝐲̃. \frac{1}{n}\mathbf X^{\mathsf T}\mathbf X \widehat{\boldsymbol\beta}_\lambda + \lambda\widehat{\boldsymbol\beta}_\lambda = \frac{1}{n}\mathbf X^{\mathsf T}\widetilde{\mathbf y}.

Multiplying by n gives

(𝐗𝖳𝐗+nλ𝐈p)𝛃̂λ=𝐗𝖳𝐲̃. \left( \mathbf X^{\mathsf T}\mathbf X+n\lambda\mathbf I_p \right) \widehat{\boldsymbol\beta}_\lambda = \mathbf X^{\mathsf T}\widetilde{\mathbf y}.

For any nonzero vector a,

𝐚𝖳(𝐗𝖳𝐗+nλ𝐈p)𝐚=‖𝐗𝐚‖22+nλ‖𝐚‖22. \mathbf a^{\mathsf T} \left( \mathbf X^{\mathsf T}\mathbf X+n\lambda\mathbf I_p \right) \mathbf a = \lVert\mathbf X\mathbf a\rVert_2^2 + n\lambda\lVert\mathbf a\rVert_2^2.

When lambda is positive, the last term is positive. The whole matrix is positive definite and therefore invertible, even if the design itself is rank deficient or has more columns than rows.

b. Singular directions

Using the compact SVD in the normal-equation solution gives

𝛃̂λ=𝐕r(𝐃r2+nλ𝐈r)−1𝐃r𝐔r𝖳𝐲̃. \widehat{\boldsymbol\beta}_\lambda = \mathbf V_r \left( \mathbf D_r^2+n\lambda\mathbf I_r \right)^{-1} \mathbf D_r\mathbf U_r^{\mathsf T}\widetilde{\mathbf y}.

Multiplying by X produces

𝐗𝛃̂λ=∑j=1rdj2dj2+nλ𝐮j𝐮j𝖳𝐲̃. \mathbf X\widehat{\boldsymbol\beta}_\lambda = \sum_{j=1}^r \frac{d_j^2}{d_j^2+n\lambda} \mathbf u_j\mathbf u_j^{\mathsf T}\widetilde{\mathbf y}.

This shows that the fitted component in direction u-j is multiplied by the requested shrinkage factor. Here, n times lambda equals 1, so

ρ1=100101≈0.9901,ρ2=45=0.8000,ρ3=0.041.04≈0.0385. \rho_1 = \frac{100}{101} \approx 0.9901, \qquad \rho_2 = \frac{4}{5} =0.8000, \qquad \rho_3 = \frac{0.04}{1.04} \approx0.0385.

Including the unpenalized intercept,

dfeff(0.01)=1+0.9901+0.8000+0.0385≈2.8286. \operatorname{df}_{\mathrm{eff}}(0.01) = 1+0.9901+0.8000+0.0385 \approx2.8286.

c. Strongest shrinkage

The third direction is shrunk the most. Its singular value is only 0.2, so the data contain little information in this direction and noise can cause a relatively large OLS change. Shrinking it reduces that part of prediction variance.

The cost would be large bias if the true mean response really had a large component in this same weak direction. Ridge would keep only about 3.85 percent of the least-squares fitted component there.

Question 4: Ridge regression and optimization

a. Condition numbers

Without the penalty,

κ(𝐀0)=90.01=900. \kappa(\mathbf A_0) = \frac{9}{0.01} =900.

With lambda 0.09, the eigenvalues become 9.09 and 0.10, giving

κ(𝐀λ)=9.090.10=90.9. \kappa(\mathbf A_\lambda) = \frac{9.09}{0.10} =90.9.

The contours are still longer in one direction, but much less extreme. Ridge adds curvature to the nearly flat direction, so the objective is easier to optimize numerically.

b. Gradient descent

For a quadratic objective,

∇Lλ(𝛃(k))=𝐀λ(𝛃(k)−𝛃̂λ)=𝐀λ𝐞(k). \nabla L_\lambda(\boldsymbol\beta^{(k)}) = \mathbf A_\lambda \left( \boldsymbol\beta^{(k)}-\widehat{\boldsymbol\beta}_\lambda \right) = \mathbf A_\lambda\mathbf e^{(k)}.

Subtracting the minimizer from the update gives

𝐞(k+1)=(𝐈p−η𝐀λ)𝐞(k). \mathbf e^{(k+1)} = \left( \mathbf I_p-\eta\mathbf A_\lambda \right) \mathbf e^{(k)}.

In a direction whose original eigenvalue is a, the ridge eigenvalue is a plus lambda, so its error multiplier is

1−η(a+λ). 1-\eta(a+\lambda).

All directions contract when

0<η<2M=29.09≈0.2200. 0<\eta<\frac{2}{M} = \frac{2}{9.09} \approx0.2200.

For eta equal to 1 divided by M, the factor in the high-curvature direction is

1−9.099.09=0, 1-\frac{9.09}{9.09}=0,

while the low-curvature factor is

1−0.109.09≈0.9890. 1-\frac{0.10}{9.09} \approx0.9890.

The first direction converges immediately, but the second one changes slowly. For eta equal to 2.1 divided by M, the factor in the largest-eigenvalue direction is

1−2.1(9.09)9.09=−1.1. 1-\frac{2.1(9.09)}{9.09}=-1.1.

Its magnitude is bigger than one. With the assumed nonzero starting error in that direction, the signs alternate and the error grows, so gradient descent does not converge.

c. Statistical tuning is different

Lambda changes the estimator, not just the speed of the algorithm. Increasing it can improve the condition number, but it also increases shrinkage bias. Step size should be chosen so the optimizer accurately solves the objective. Lambda should instead be chosen using prediction information such as cross-validation or GCV.

fit_ridge <- function(X_raw, y, lambda, X_new = NULL) {
  n_fit <- nrow(X_raw)
  p_fit <- ncol(X_raw)

  x_mean <- colMeans(X_raw)
  X_centered <- sweep(X_raw, 2, x_mean, "-")
  x_scale <- sqrt(colMeans(X_centered^2))
  if (any(x_scale == 0)) stop("A predictor has zero scale.")
  X_scaled <- sweep(X_centered, 2, x_scale, "/")

  y_mean <- mean(y)
  y_centered <- y - y_mean
  beta_scaled <- solve(
    crossprod(X_scaled) + n_fit * lambda * diag(p_fit),
    crossprod(X_scaled, y_centered)
  )

  fitted <- y_mean + drop(X_scaled %*% beta_scaled)
  new_fitted <- NULL
  if (!is.null(X_new)) {
    X_new_scaled <- sweep(X_new, 2, x_mean, "-")
    X_new_scaled <- sweep(X_new_scaled, 2, x_scale, "/")
    new_fitted <- y_mean + drop(X_new_scaled %*% beta_scaled)
  }

  d <- svd(X_scaled, nu = 0, nv = 0)$d
  df_eff <- 1 + sum(d^2 / (d^2 + n_fit * lambda))

  list(
    fitted = fitted,
    new_fitted = new_fitted,
    df_eff = df_eff
  )
}
